# Archive Hub

Selamat datang di Archive Hub RKK. 

- **Fungsi**: Folder ini difungsikan sebagai Archive Hub (pusat arsip) untuk menyimpan dokumentasi lama dan riwayat pengembangan yang sudah berlalu.
- **Isi**: Dokumentasi yang berada di sini (`docs-legacy/` dan lainnya) merupakan dokumentasi historis.
- **Status**: Arsip ini **bukan** sumber keputusan aktif. Dokumen di dalam arsip hanya berfungsi sebagai riwayat dan bahan pembanding.
- **Sumber Kebenaran**: 
  - Keputusan resmi bisnis, produk, dan arsitektur berada di Google Drive proyek.
  - Implementasi aktual berada di dalam *source code* repository GitHub ini.
