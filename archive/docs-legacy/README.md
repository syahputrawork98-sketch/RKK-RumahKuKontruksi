# Arsip Dokumentasi Historis RKK

Selamat datang di Arsip Dokumentasi Historis RKK (RumahKu Konstruksi). Folder ini adalah arsip dari dokumentasi lama yang saat ini **TIDAK AKTIF** dan hanya digunakan sebagai referensi historis.

## Struktur Arsip
- `project/` - Arsip manajemen proyek, workflow sistem, instruksi onboarding, status terkini, history fitur, dan baseline kondisi proyek.
- `frontend/` - Arsip catatan teknis dan arsitektur untuk frontend.
- `backend/` - Arsip catatan teknis dan arsitektur untuk backend API.
- `database/` - Arsip catatan teknis untuk struktur database dan layanan Supabase.

*Catatan: Source of truth aktif adalah README root repositori dan dokumen perencanaan di `docs/plan/`. Dokumen di folder ini tidak lagi menjadi sumber keputusan aktif.*

## Urutan Membaca Historis
Bagi yang memerlukan pemahaman arsitektur lama, silakan membaca dokumen berikut:
1. `README.md` (root repository - status transisi)
2. `FITUR.md` (ringkasan fungsional)
3. `archive/docs-legacy/README.md` (dokumen ini - indeks arsip)
4. `project/README.md`
5. `project/onboarding/CHATGPT_PROJECT_INSTRUCTIONS.md`
6. `project/workflow/WORKING_SYSTEM.md`
7. `project/history/CURRENT_STATUS.md`
8. `project/history/FEATURE_HISTORY.md`
9. `frontend/README.md` / `backend/README.md` / `database/README.md` sesuai dengan scope arsip.
