# RKK Documentation Center

Selamat datang di Pusat Dokumentasi RKK (RumahKu Konstruksi). Folder `docs/` ini adalah tempat utama untuk melacak arsitektur, workflow, dan progres dari proyek RKK. 

## Struktur Dokumentasi
- `archive/docs-legacy//` - Manajemen proyek, workflow sistem, instruksi onboarding, status terkini, history fitur, dan baseline kondisi proyek.
- `archive/docs-legacy//` - Catatan teknis dan arsitektur untuk frontend.
- `archive/docs-legacy//` - Catatan teknis dan arsitektur untuk backend API.
- `archive/docs-legacy//` - Catatan teknis untuk struktur database dan layanan Supabase.

*Catatan: Source of truth aktif adalah README root dan folder di atas. Folder `docs/_legacy/` berisi dokumen lama yang dikarantina, dan `archive/docs-legacy//migration/` berisi tracker migrasi dokumen lama tersebut.*

## Urutan Membaca (Onboarding)
Untuk memahami proyek ini dari awal, silakan ikuti urutan membaca berikut:
1. `README.md` (root repository)
2. `FITUR.md` (ringkasan fungsional)
3. `docs/README.md` (dokumen ini)
4. `archive/docs-legacy//README.md`
4. `archive/docs-legacy//onboarding/CHATGPT_PROJECT_INSTRUCTIONS.md`
5. `archive/docs-legacy//workflow/WORKING_SYSTEM.md`
6. `archive/docs-legacy//history/CURRENT_STATUS.md`
7. `archive/docs-legacy//history/FEATURE_HISTORY.md`
8. `archive/docs-legacy//baseline/`
9. `archive/docs-legacy//README.md` / `archive/docs-legacy//README.md` / `archive/docs-legacy//README.md` sesuai dengan scope pengerjaan.
